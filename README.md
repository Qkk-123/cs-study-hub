## 背景

名称取自《论语》"知之为知之，不知为不知，是知也"。课上知其然，卷上答其所以然——听懂了却推不出公式、看懂了却不知从哪下手，这个站点就是为这两个断点做的。每个单元按课本小节编排，包含：

- **知识点详解**：定义 + 公式 + 推导过程 + 易错点，点击知识点标签可弹出深入讲解
- **公式推导**：不止给结论，给"为什么"，配 SVG 图解与动画辅助理解
- **题型攻坚卡**：识别 → 思路 → 步骤 → 例题 → 易错 五段式，对标课本例题
- **规范作答示范**（概率论）：设事件 → 写公式 → 代入 → 作答，解决答题格式问题

## 技术栈

- **零依赖单文件 SPA**：原生 HTML / CSS / JavaScript，无构建步骤、无 CDN、无外部字体，双击即可离线打开
- **Hash 路由**：首页 → 科目知识地图 → 单元讲义三级结构（`#/`、`#/s/:subject`、`#/u/:subject/:unit`）
- **交互**：思维导图导航、知识点弹层、例题折叠展开、代码一键复制、SVG 图解/动画、计组 3D 硬件透视（CSS 3D）、鼠标跟随交互
- **设计规范**：按 [impeccable](https://github.com/pbakaus/impeccable) 设计语言打磨——实色表面（去毛玻璃）、统一缓动 `cubic-bezier(.16,1,.3,1)`、焦点环/选区/滚动条主题化、`prefers-reduced-motion` 支持、数字等宽对齐

## 使用说明

1. 直接打开 <https://qkk-123.github.io/cs-study-hub/>，或本地双击 `index.html`（无需联网）。
2. 首页点击科目卡片进入**知识地图**，再点击任意单元进入**攻坚讲义**。
3. 讲义中：
   - 点击**知识点标签**查看深入讲解；
   - 点击**例题标题**折叠/展开完整解答；
   - 代码块右上角可**一键复制**。
4. 页面顶部导航可随时切换科目或返回首页。

## 部署

本站点是纯静态单文件，可托管到任意静态服务。本项目使用 GitHub Pages：

1. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch`，分支 `main` / `(root)`；
2. 保存后稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`。
